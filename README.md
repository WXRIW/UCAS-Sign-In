<h1 align="center">果壳签到</h1>

<p align="center">为国科大轻新课堂打造的多平台原生客户端，支持课表查询、课程签到、动态二维码生成和课程提醒。</p>
<p align="center">iOS · iPadOS · macOS · Windows · Android </p>

## 功能概览

- **账号登录**：支持 SEP 邮箱或轻新课堂学号，可选择记住密码。
- **多账户切换**：在本机保存多个学校账户，从今日页、桌面侧栏或账户管理页快速切换。
- **iCloud 同步（Apple 平台）**：默认启用，在同一 Apple 账户的设备间同步学校账户、登录状态、普通偏好和操作记录；自动签到设置与执行控制保留在各设备。
- **课表查询**：支持日视图与周视图切换，按真实上课时间查看整周安排，展示学校提供的教室；整学期课表缓存可离线浏览，自动记住视图选择。
- **课程目录**：浏览当前学期的全部课程，按课程名、编号或教师搜索，查看教师、教室和课程日期；优先展示缓存，按有效期更新，也可手动刷新。
- **学校考勤**：查看每门课程的已签到／未签到数量和课次明细，与应用中的签到操作记录分别展示。
- **课程签到**：手动签到、自动签到，以及与学校时间同步的动态二维码。
- **课程偏好**：每门课程的提醒、手动签到二次确认和自动签到可跟随账户默认值，也可单独启用或停用；还可禁用某门课程的签到，保留二维码显示。
- **课程提醒**：为已同步课程发送课前本地通知，默认提前 10 分钟，可选择 5、10、15 或 30 分钟，并为单门课程单独设置。
- **版本更新**：自动检查新版本，也可在设置中手动检查；Windows 商店版通过 Microsoft Store 更新。
- **桌面小组件（仅 Apple 平台）**：支持小号、中号、大号、超大号，以及新系统上的竖向超大号，展示今日课程与签到状态；课程结束后自动向后递补，时间格式跟随系统，超大号可用双列展示更多课程。
- **账户隐私**：一键将姓名脱敏、隐藏学号；Apple 平台开启 iCloud 同步时也同步隐藏偏好。
- **演示模式**：无需账号即可体验课表和模拟签到，支持浅色、深色外观。

### 登录与课程签到

1. 点击「连接学校账号」，使用 **SEP 邮箱与密码**，或 **轻新课堂学号与密码**登录。
2. 在「今日」查看当天安排，或进入「课表」切换「日 / 周」视图，选择日期、浏览整周课程；点击课程可打开详情。在「设置 → 课表」开启「显示非本周课程」后，周课表会以浅灰色显示同一学期其他周的课程安排，默认关闭。
3. 在首页点击「一键签到」，或从日课表打开课时详情，查看动态二维码、点击「为本节课程签到」。周课表打开课程信息与考勤页面。签到结果以学校返回状态为准。
4. 在账户页的签到记录中查看当前账号的操作结果。Apple 平台开启 iCloud 同步后，也可查看其他设备产生的记录。

同一学期中，能通过课程编号唯一关联到课程目录的多教师安排，在日期、起止时间和教室相同时合并为一张周课表卡片。点击后打开课程页，多位教师共用该课程的设置和考勤统计；每条签到记录仍保留独立身份。无法可靠关联的安排保持独立显示。

课表前后周按钮限制在所查看学期的起止日期内。右上角的学期菜单支持切换到接口提供的历史学期，切换时保留周次，目标学期周数不足时取最后一周，并尽量保留星期几。日期选择器仅允许选择所查看学期内的日期。点击日／周视图顶部的年月或“第 N 周”，可快速选择该学期的周次。学期开始日所在周为第 1 周，每周一递增；学期之间的假期不显示周次。

欢迎页点击「先体验一下」可进入演示模式，不影响真实账户，也不向学校提交签到，二维码无签到效力。

iPhone / iPad / Android 下拉刷新课程；Mac 点击刷新按钮或按 `⌘R`，Windows 点击刷新按钮或按 `Ctrl+R`。课表页日视图刷新所选日期，周视图刷新所查看的完整学期；切换页面或视图不会重置日期。

Apple、Android 和 Windows 的学期列表、课程目录（含历史学期）和完整课表统一缓存七天，分别从各自最近一次成功更新计时；手动刷新绕过期限。过期时先展示已有内容，更新失败保留缓存和原更新时间。课程增删、时间、教室或教师发生变化时按需重新同步。周视图底部的时间仅代表排课完整同步时间，不代表签到状态已经核实。

今日、日课表和签到详情在进入页面、切换日视图日期、恢复前台或手动刷新时核实签到状态；同一日期的并发查询合并，非手动进入在成功查询后三十秒内复用结果。停留页面不会持续轮询签到状态。周模式切换日期、周次或学期不查询隐藏日视图；切回日模式才核实所选日期。完整课表同步仍会补查周接口遗漏的日期。

缓存中的旧“未签到”或学校返回的缺失、异常状态显示为“状态待同步”，核实前不能用于签到。本机签到成功立即保存并查询一次；后续相冲突的查询保留“已签到 · 待核验”，再次进入页面、恢复前台或手动刷新时继续核实，不安排定时复查。第一次冲突保留成功状态；后续正常查询再次从同一来源得到明确未签到结果，且期间没有已签到或未知结果时，才接受学校纠正，不设置额外等待时间。自动签到不会重复提交已成功的课次，提交前必须取得六十秒内的明确未签到结果。

学校考勤详情仍缓存五分钟，签到成功立即使相关缓存失效，下一次打开或刷新详情时再获取；统计总数始终采用学校响应。签到证据与待核验状态按账户独立保存，旧课表缓存继续可用，无需重新登录。网络恢复后可点击「重新同步」。

### 添加、切换与移除账户

在「账户 → 切换与管理账户」添加、切换或移除账户。各账户的会话、缓存、签到记录和偏好独立保存；重新打开 App 会恢复本机上次选中的账户。Apple 平台可选择「仅从本机移除」或「从 iCloud 和所有设备删除」；前者保留云端与其他设备的数据，后者在同步完成后从其他设备移除该账户。Windows 和 Android 的移除操作只清除本机数据。其他学校账户不受影响。

不记住密码也能保留有效会话。会话失效时，已记住密码的账户会尝试自动恢复，否则提示重新登录；恢复过程不会重复提交签到。

### iCloud 同步（Apple 平台）

iOS、iPadOS 和 macOS 默认开启 iCloud 同步，可在设置中关闭、查看状态或手动同步。实际同步需要使用同一 Apple 账户，并安装已配置相同 iCloud 容器与钥匙串共享权限的签名版本；登录信息还需要系统 iCloud 钥匙串可用。未配置这些能力的源码构建、未签名或自行重签名版本可继续使用本机功能，但不保证具备 iCloud 同步能力。签名配置见 [Apple 开发说明](apps/apple/README.md)。

- 同步学校账户身份、登录用户名、完整会话和选择记住的密码。会话与密码通过可同步 Apple Keychain 传递，账户资料、普通设置与历史记录保存在 iCloud 私有 CloudKit 数据库；本项目不设同步服务器。
- 同步外观、姓名学号隐藏、课表显示、自动检查更新，以及账户和课程的提醒、手动签到确认、禁用课程签到等普通偏好。每台设备仍单独决定当前账户，并使用本机通知授权安排提醒。
- 同步签到操作记录和自动签到执行历史的展示副本。Apple 平台默认不限数量和保留时间；可在“设置 → 记录保留”分别为两类记录设置数量上限、保留天数，支持自定义正整数，关闭限制即不限，各账户分别计算。保存后按设置清理超额或过期记录，保留设置也在 Apple 设备间同步。
- 多设备修改自动合并；记录不代表学校最终考勤，其他设备的执行历史不会在本机恢复执行或重试。调整历史保留范围不影响正在执行的任务和本机防重复签到状态，此前已清理的记录不会恢复。
- 本地变更合并后约 2 秒同步；其他设备收到 CloudKit 静默变更通知后增量拉取，前台约每分钟轮询兜底。推送需要主 App 的 Push Notifications 签名权限，后台到达由系统调度，不能保证实时；不会为同步弹出通知或申请提醒通知权限。
- 课表、课程目录、学校考勤缓存、小组件快照不上传 iCloud，继续从学校获取或在本机生成。所有自动签到开关、规则、课程与单次例外、暂停状态、执行进度及防重复提交状态保留在本机；新设备不会因为同步账户而开启自动签到。

关闭应用内同步会停止本应用继续交换数据，保留本机和已有云端数据。此前已写入可同步钥匙串的项目仍由系统 iCloud 钥匙串管理，系统可能继续同步既有项目；关闭开关不等于删除云端登录信息。需要清除某个账户的云端副本时，使用账户管理中的「从 iCloud 和所有设备删除」，并在同步可用时等待删除完成。离线设备会在后续同步后处理删除。

### 自动签到与课程提醒

在「账户 → 设置 → 自动签到」用一个开关控制当前账户的自动签到。开启后，课程默认参与，可在课程详情中停用个别课程或在单次计划中跳过课次。“默认规则”可调整执行时间、错过处理、最多提交次数（1～3 次）、重试间隔（1／2／5 分钟）与结果通知。默认课前 5 分钟执行；错过计划时间超过 60 秒后不补签，提示手动处理。“未来七天计划”只列参与课次，通过“选择课次”可单独启用其他课次；点击计划进入单次详情，课程详情可覆盖账户默认规则。调整默认或课程规则不会自行开启自动签到。

总开关关闭后，主页隐藏自动签到卡片，课程与单次例外也不会执行。初始化、同步、预览和配置修改不新建执行历史；已启用任务实际到期核实或有效错过后才建立记录。执行记录按课程和上课时间展示，点击可查看事件时间线。重新开启、恢复暂停或重新启用课程与课次时，略过启用前已过去的计划，保留既有提交次数和核实证据。升级会原子清理明确属于纯预览的旧记录，保留实际执行和防重复状态；记录读取或保存失败时暂停自动提交，故障显示在自动签到页面。

重试前会重新核实学校状态；请求结果不明时，须在提交后取得两次间隔至少 30 秒的明确未签到结果。提交次数上限只限制提交，最后一次结果不明仍继续核实；确认成功后更新执行记录。旧记录若缺少可靠的学校提交时间，只继续核实，不再自动重试。已有本机成功记录或执行记录无法保存的课次不会再次自动提交。升级保留原有账户和课程开关，使用新的默认时间与重试规则。**只有当前账户运行自动签到和课程提醒**，切换账户后会重新安排提醒。课程提醒和自动签到结果通知需要通知权限，分别管理；关闭或重排课程提醒不会删除自动签到结果通知。课程提醒不会触发签到。

| 平台 | 自动签到运行条件 |
| --- | --- |
| iOS / iPadOS | App 在前台活跃时运行。 |
| macOS / Windows | App 运行期间可最小化窗口或切换到其他应用；Mac 也可关闭窗口。退出 App 或设备睡眠后暂停。 |
| Android | 通过带常驻通知的前台服务运行；省电、自启动限制或强行停止 App 可能使任务延迟或中断。 |

### 桌面小组件（Apple 平台）

登录并同步今日课程后，从系统的小组件列表添加「果壳签到 · 今日课程」。小组件展示当前账户的课程，不会独立联网或签到；数据未更新时请打开 App 刷新。演示模式不提供小组件数据。

## 数据与隐私

完整说明请参阅[《果壳签到隐私政策》](PRIVACY.md)。

- 学校账户与课程请求通过 HTTPS 直接发送至学校服务，不经过本项目自建服务器。
- 账户凭据由平台安全存储保护，仅在选择记住密码时持久保存密码；Apple 平台默认启用 iCloud 同步，会话与已记住的密码通过可同步 Keychain 传递。
- Apple 的普通设置和操作记录通过 iCloud 私有 CloudKit 数据库同步，自动签到设置和执行控制保留在各设备；Windows 和 Android 不参与 iCloud 同步。
- 所有平台的操作记录和自动签到历史默认不限数量与时间。可在“设置 → 记录保留”分别为两类记录设置数量上限、保留天数，也可同时启用或关闭限制；限制按账户分别计算。保存后清理超额或过期记录，未完成任务与防重复签到状态继续保留，已清理的数据不会恢复。Android、Windows 的保留设置与记录仅保存在本机。这些记录不代表学校完整考勤，Apple 跨设备的自动签到历史只用于展示。
- App 不申请定位、通讯录或相机权限，未集成广告或统计 SDK。
